Optional: Terraform (CLI) version

Builds the security group and instance from code. Follows the setup steps of the HashiCorp AWS get-started tutorial.

Terraform creates resources. Use it in a fresh account, or ask the instructor first. Running it in the shared workshop account would try to create duplicates. The four Plaid values must already be in Parameter Store (SecureString).
  • Install Terraform 1.2 or newer and the AWS CLI. Check with terraform -version and aws --version.
  • Authenticate with the access key from your instructor. Prefer a role or SSO sign-in if your instructor provides one.
  • In the terraform folder, copy terraform.tfvars.example to terraform.tfvars. Set bucket_name, participant_name, and my_ip_cidr (your IP with /32).
  • Run terraform init, terraform validate (expects "Success! The configuration is valid."), then terraform apply and type yes.
  • Run the Step 4 to Step 6 deploy and check using the new instance. Clean up with terraform destroy. The bucket must be empty first.
